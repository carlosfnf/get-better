If the HUD says WebGPU is available, pick the 🚀 engine in Settings → Advanced and restart — GPU inference works even in a plain about:blank tab, no special headers required.

🧵 CPU multi-thread only (COOP/COEP)

Only needed if you can't use WebGPU. Serve this file instead of opening it directly:

// serve.mjs — run: node serve.mjs  →  http://localhost:8000
import http from 'node:http';
import { readFile } from 'node:fs/promises';
http.createServer(async (req, res) => {
  res.setHeader('Cross-Origin-Opener-Policy', 'same-origin');
  res.setHeader('Cross-Origin-Embedder-Policy', 'require-corp');
  try {
    const path = req.url === '/' ? '/index.html' : req.url;
    res.end(await readFile('.' + path));
  } catch {
    res.statusCode = 404; res.end('Not found');
  }
}).listen(8000);

⚡ Token speed

Prompt batch 2048

KV cache q8_0 halves cache RAM and speeds up long-context decoding; batch 2048 speeds up prompt processing. If the engine rejects a combo (e.g. Flash Attention unsupported on WebGPU), it auto-retries with safe settings. Applies on restart — use ⚡ Speed Test before/after to compare.
